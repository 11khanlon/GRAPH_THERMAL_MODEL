8-bit vs 16-bit 

16 bit does not mean more pixels 

.tiff file 16 bit:
Shape = (480, 640)
dtype = uint16

lets say this is 8-bit:
It would still contain Shape = (480, 640)

The difference in the teo remains in how many values each pixel can store 
For 8-bit, a pixel can store 256 values 
16-bit can store 2^16 values or 65,536 values
