Graph-theory heat conduction solver
Implements the spectral solution presented in
- Section 4.3.1.4
- Section 4.3.1.6

Paper Equations:
(15) Tc = Φ exp(-alpha g Λ tb) Φᵀ T0
(17) TLc = Φ exp(-alpha g Λ t) Φᵀ Tb

where

Φ  = Laplacian eigenvectors
Λ  = Laplacian eigenvalues
alpha  = thermal diffusivity
g  = gain factor
t  = timestep

This module performs ONLY heat conduction --> It does not apply laser heating or convection

def propagator(self, alpha, dt):
This constructs Φ exp(-alpha g Λ dt) Φᵀ 
Return: ndarray, Spectral propagation matrix

lambda_values = np.array([0,2,5])
then np.exp(-lambda_values) automatically returns 
[exp(0), exp(-2), exp(-5)]. There is no loop, numpy performs the loops internally 

D = np.diag(decay)
suppose decay = [1, 0.84, 0.31] 
This creates a 3x3 matrix with the values at the diagonal 

return self.phi @ D @ self.phi.T
This is multiplying the eigenvectors and transpose of it by the soltuion to the decay problem 
@ means matrix multiplication

def step(self, temperature, alpha, dt):
Advance one conduction timestep
Implements Equation (15): Tc = Φ exp(-alphagΛdt) Φᵀ T

Parameters:
temperature : ndarray, Current nodal temperatures.
alpha : float, Thermal diffusivity
dt : float, Time step

Returns:
ndarray --> Updated temperatures after conduction.

P = self.propagator(alpha, dt) 
--> this builds Φ exp(-alpha g Λ dt) Φᵀ
--> describes how heat diffuses through your graph during that timestep

return P @ temperature
This multiplies the created P vector by temperature 
This give the new temperature state that you will use to iterate in deposition

Tnew = P@T0
There is no finite difference loop 
There is n oexplicit neighbor update 
The matrix multiplication updates every node simultaneously

What enters ConductionSolver? 

1. Heat Initial block and determine temperature state 1
Input intial node temperatures (25 deg C) in each block to laser model 
T0 = heat.apply(nodes, block, temperature)
This is a numerical vector containing one temperature for everynode in the graph 

2. Multiply T0 from Goldak to Conduction equation
Input the T0 vector as "temperature" into block_conduction to obtain T1 state temperatures 
T1 = solver.block_conduction(
    temperature=T0,
    alpha=alpha,
    block_time=BLOCK["time_per_block"])

3. Repeat 
Take previous state, T1, and pass it into laser heating operation 
Now block 2's nodes recieve heating on top of whatever temperature they already had
However, this should just be 25 deg C because you loop over the nodes in block.nodes (current block set by deposition manager)

This is why temperature.copy() is important from heat_source.py 
This makes a copy of the current temperature state so that you can modify
temperatures caused bu this laser pass without overwriting the input vector

For example: 
If temperature = [1800, 1800, 100, 100, 25, 25]
then temperature.copy() gives [1800, 1800, 100, 100, 25, 25]

Then heat_block() modifies the entries corresponding to the currently deposited block 
T[index] = max(T[index], delta), if the laser raises this node above its current temperature, 
its current temperature is replaced with the hotter value

propagate(): 
Repeatedly apply conduction
Useful for arbitrary simulation times

Suppose you want to simulate 30 seconds
Instead of writing step(), step()... repeatedly, call propogate() 

Parameters:
temperature : ndarray
alpha : float
total_time : float
dt : float

Returns: ndarray

T = temperature.copy() --> creates sopy of the temperature vector 
Dont overwrite the original temperature 

nsteps = int(np.ceil(total_time/dt))
Suppose total_time/dt = 5.3 
np.ceil will round up to 6 seconds 
therefore 6 steps are performed 

for _ in range(nsteps):
this loops nsteps number of times 
Each iteration advances the temperature by one timestep
