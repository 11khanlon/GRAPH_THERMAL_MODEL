Random node settings: 
NODES = {
    "seed": 42,
    "random": True
}

This controls how graph nodes are generated 
with a seed every run gives the exact same sequence

Example:
seed = 42
every run gives: 0.3745, 0.9507, 0.7319...
The seed only fixes the random number generator, each seed produces the same random node cloud
