Laser heat source model
Produces the initial nodal temperature field T0 before conduction begins
This module ONLY applies laser heating
--> No conduction.
--> No convection.
--> No graph operations

Implements Section 4.3.3
Goldak's double ellipsoid model (Paper Equation 19)

class GoldakHeatSource:
This class represents one object (the laser heat source)
Notice how this instance has many inputs compared to the other objects 

These are the qualities that each goldak heat source contains: 
self.P = laser_power
self.k = conductivity
self.alpha = diffusivity
self.V = scan_speed
self.C = scaling_factor

self.Tmelt = meltpool_temperature
self.Tliquidus = liquidus_temperature

def goldak_temperature(self, x, y, z):
Equation 19 from paper 

r = np.sqrt(x**2 + y**2 + z**2), r computes the distance from the laser 
r = np.maximum(r, 1e-8) prevents the division by zero 

temperature = (
            self.C * self.P
            / (2 * np.pi * self.k * r)
            * np.exp(
                -(self.V / (2 * self.alpha))
                * (x + r)
            )
        )
T0(x, y, z, t) =  is the temperature at time t 
P = laser power 
k = thermal conductivity 
C = dimensionless scaling factor 
V = laser velocity
alpha = thermal diffusivity
