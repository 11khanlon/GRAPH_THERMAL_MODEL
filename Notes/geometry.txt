----- Create Block Class -------
Need for OOP: 
Instead of creating hundreds of variables 
and storing them within one script, create one object 

class Block:
A class is a blueprint and frame for creating objects 
This initializes the structure for object oriented programming 
Each deposited block will have the same properites below:
ID, layer number, location, temperature, nodes, active status 

def __init__(...)
this function runs automatically when a new block is created 
this initilizes the variables involved

self.id = block_id
each block gets a unique integer
example: block 0, block 1, block 2

self.layer = layer 
this stores which layer the block belongs to 

Start position: 
self.start = np.array(start) 
which is the lower corner of the block 

End Position: 
self.end = np.array(end)
the opposite lower corner

Center: 
self.center = (self.start + self.end)/2
instead of storing the corners the program also computes the center 

Active: 
self.active = False
the block is initially false because the laser has not reached the block 
Then if its true later, then the laser has reached the block

self.nodes = []
this is initially empty
later this list will contain graph nodes inside the block

self.node_indices = []
this will include the indices of the nodes 
Later during deposition, instead of searching each node, 
you loop over each block on turn on the node indices in there 

substrate info: 
is_substrate=False (initially turned off because deposition hasn't started yet)
self.is_substrate = is_substrate
self.active = is_substrate

Temperature:
self.temperature = None 
this is initially unknown

region = "Substrate" if self.is_substrate else "Deposition"

if self.is_substrate:

Every python file has a special built-in variable called __name__
Case 1: You run the file directly 
then python sets __name__ = "__main__"
so this code then runs:

if __name__ == "__main__":
    geom = Geometry("example_part.stl")
    geom.build_blocks()
    print(geom.blocks[0])

Case 2: Another file imports it 
Suppose main.py contains 
from geometry import Geometry

geom = Geometry("part.stl")
geom.build_blocks()

when geometry.py is imported Python sets __name__ = "geometry" 
now the condition if __name__ == "__main__":  is skipped
